Goal: Modernize the `TonyHsieh/setup-linux-scripts` repository into a declarative Nix setup.

Target Environment:
- Cross-platform support: Linux (Ubuntu, WSL, NixOS) and macOS (Darwin).
- Tooling: Nix Flakes, Home Manager, and devenv.

Requirements:
1. Replace procedural shell setup scripts with a declarative `flake.nix` and Home Manager modules (`home/default.nix`, shell configurations, dotfile symlinks).
2. Integrate `devenv` for project-level toolchains and isolated environments without virtualization overhead.
3. Structure the flake outputs to cleanly separate Linux (`x86_64-linux`) and macOS (`aarch64-darwin`) configurations.

Current Proposed Structure:
setup-linux-scripts/
├── flake.nix              # Multi-platform entry point (homeConfigurations)
├── flake.lock             # Dependency lockfile
├── home/
│   ├── default.nix        # Core packages & environment variables
│   ├── git.nix            # Git configuration
│   └── shell.nix          # Shell/aliases
└── dotfiles/              # Managed configurations
