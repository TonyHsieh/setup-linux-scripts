🔍 Diagnostic & Root Cause Breakdown

✓ 1. ble.sh Restored (Root Cause Resolved)
Resolved: Removed Inherited BLE_SESSION_ID Poison Guard
Root Cause: In commit 3535c97, -z "${BLE_SESSION_ID:-}" was added to guard subshells. However, ble.sh runs export BLE_SESSION_ID=... on line 9703. Because it was exported into the environment, every subsequent child process, terminal window, and tmux pane inherited $BLE_SESSION_ID. The check evaluated to false, permanently disabling ble.sh everywhere.

Fix Applied: Removed -z "${BLE_SESSION_ID:-}" from both early init and late attachment blocks in home/shell.nix. Retained -z "${DEVENV_ROOT:-}" and -z "${IN_NIX_SHELL:-}" so that active devenv and nix-shell environments continue to safely suppress ble.sh.
✓ 2. Tmux Tiled Window Restoration & Ghost Session Elimination
Resolved: Canvas Expanded to 350x90 & Smart Auto-Attachment Added
Root Cause A (Layout rejection): In headless/continuum restores, tmux defaults to default-size 80x24. Resurrect's saved 346x79 tiled layout was rejected because 346x79 did not fit in an 80x24 detached canvas.
Fix Applied: Added set -g default-size 350x90 and set-hook -g client-attached 'select-layout -E' in home/tmux.nix.

Root Cause B (Manual Ctrl-B s picking): Running tmux without arguments spawned redundant numeric sessions (3, 4, 5, 6). Continuum saved state 6, so upon restore, the user landed in a single blank pane.
Fix Applied: Added smart tmux() launcher and t alias in home/shell.nix to automatically attach to existing Session 0. Pruned ghost sessions 3, 4, 5, 6 and re-saved resurrect snapshot with state 0.
