## 🧭 3. Rules & Methods to Keep the Setup Coherent, Manageable, & Usable

To prevent configuration drift, package manager confusion, or system pollution over the coming months, adhere to these simple operational rules:

### Rule 1: The Golden Rule of Compilers
> **Never install language compilers (`rustc`, `node`, `python`, `go`) globally in `home/packages.nix` or via host package managers (`apt`/`brew`).**  
> Always declare compilers inside the project's `devenv.nix`. This completely eliminates version clashes between projects.

### Rule 2: Tier Governance (Where Changes Belong)
* **Need a CLI tool everywhere?** (`bat`, `htop`, `duf`)  
  $\rightarrow$ Add to [`home/packages.nix`](home/packages.nix), run `./bootstrap.sh`.
* **Need a global shell alias or environment variable?**  
  $\rightarrow$ Add to [`home/shell.nix`](home/shell.nix), run `./bootstrap.sh`, then `exec bash`.
* **Need a local web service or database?** (Kavita, Ollama, Redis, Plex)  
  $\rightarrow$ Add to [`local-services/docker-compose.yml`](local-services/docker-compose.yml), route via Traefik labels, run `jl up`.
* **Need tools for a repository or class?** (CKAD, Python API, React app)  
  $\rightarrow$ Initialize `nix flake init -t github:TonyHsieh/setup-linux-scripts#<stack>`, run `direnv allow`.

### Rule 3: Flake Health & Atomic Rollbacks
* **Validate changes before applying**:
  ```bash
  nix flake check
  ```
* **Dry-run Home Manager**:
  ```bash
  ./bootstrap.sh --build
  ```
* **Instant Rollback**: If an update ever introduces an unwanted change:
  ```bash
  home-manager generations
  home-manager switch --generation <ID>
  ```

### Rule 4: Routine Maintenance & Disk Hygiene
* **Clean Devenv Project Caches**:
  ```bash
  devenv gc
  ```
* **Garbage-Collect Old Nix Generations**:
  ```bash
  nix-collect-garbage -d
  ```
