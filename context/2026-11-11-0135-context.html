Ubooquity 502 on Tailscale local-tailscale-books was running for 12 days and held stale in-memory proxy target local-kavita:5000. When Kavita was stopped, proxy failed with Connection Refused. Restarted local-tailscale-books to reload serve-books.json pointing to http://local-ubooquity:2202. Verified HTTP/2 200 OK on web and OPDS.
Ubooquity Root Prefix (500 Error) Default container configuration had "reverseProxyPrefix": "ubooquity", causing requests to root URL / or /books to return Jetty 500 error. Used podman unshare to configure "reverseProxyPrefix": "" and "isOpdsProviderEnabled": true in preferences-2.json, enabling clean root URLs.
Devenv Rust WASM Cross-Compilation Using languages.rust.targets = ["wasm32-unknown-unknown"] with default channel = "nixpkgs" threw devenv assertion error because nixpkgs channel does not support target cross-compilation. Configured languages.rust.channel = "stable" with targets = ["wasm32-unknown-unknown"], resolving cleanly in devenv devShell.
Track B Templates Manifest Auto-Sync Need unified developer guidance and auto-sync across Go, WASM, Effect, and Scala without crashing when manifests are missing.
