🏆 Key Accomplishments & Incident Resolutions

1. Multi-User Nix Daemon Trust on Scratch Installation (Dominator)

Incident: On a fresh WSL install using the Determinate Nix installer, running ./bootstrap.sh resulted in warning: ignoring untrusted substituter 'https://cache.numtide.com', you are not a trusted user. This caused Nix to bypass precompiled binary caches and attempt local source compilation of slack-bolt and nemo-relay.
Root Cause: The Nix daemon evaluates trusted groups (e.g. @sudo) against the connecting socket user's primary GID. On Ubuntu, user tonyh has primary GID 1000 (tonyh) while sudo is supplementary GID 27. Because supplementary groups are ignored by the socket check, @sudo alone failed to grant trust.
Resolution: Implemented setup_nix_daemon_trust() in bootstrap.sh to dynamically verify administrative access and configure trusted-users = root $USER @sudo @wheel @admin and Numtide substituters in /etc/nix/nix.conf locally, followed by a daemon restart. Scratch installer now executes with --extra-conf.

2. Hermetic Neovim Toolchain for LazyVim (No Global Compiler Pollution)

Incident: Launching Neovim on a fresh machine produced Treesitter parser warnings: Unmet requirements for nvim-treesitter main: C compiler, curl, tar, tree-sitter (CLI).
Root Cause & Architecture: LazyVim compiles .so parsers dynamically. However, installing gcc into global home.packages or running sudo apt install build-essential violates Prime Directive 2 (Never Install Global Compilers).
Resolution: Created modular home/neovim.nix using Home Manager's programs.neovim.extraPackages. Nix generates a wrapper script for nvim that prefixes its internal execution $PATH with gcc, gnumake, tree-sitter, curl, gnutar, ripgrep, and fd. Neovim compiles parsers seamlessly while global shell $PATH remains 100% free of compiler pollution.

3. Podman-Compose Volume Parsing Bug in jl up-all

Incident: Running jl up-all failed with RuntimeError: volume [$HOME/Books] not defined in top level.
Root Cause: podman-compose uses a non-recursive regex (var_re) to substitute environment variables and checks dir_re = re.compile(r"^[~/\.]") to distinguish host bind mounts from named volumes. Because ${BOOKS_DIR:-$HOME/Books} evaluated literally to $HOME/Books without expanding $HOME, it failed the ^[~/\.] prefix check and was treated as a missing named Docker volume. Furthermore, nested fallback ${BOOKS_DIR_2:-${BOOKS_DIR:-...}} broke on the first closing }, leaving an invalid trailing }.
Resolution: (1) Exported BOOKS_DIR, BOOKS_DIR_2, COMICS_DIR, and MEDIA_DIR directly in local-services/justfile. (2) Changed compose defaults from $HOME/Books to ~/Books (natively supported by Python's os.path.expanduser). (3) Added automatic mkdir -p "$BOOKS_DIR" "$MEDIA_DIR". Verified clean via podman-compose --profile all config.

4. Hack Nerd Font Setup across WSL2, macOS, and Arch/CachyOS

Incident: winget install --id NerdFonts.Hack -e failed with No package found matching input criteria on Windows 10.
Resolution: Identified that NerdFonts.Hack is not published in the winget repository. Documented the verified 1-line PowerShell installer (Install-NerdFont.ps1), direct GitHub zip releases, and Scoop/Chocolatey options in README.md. Resolved Windows 10 legacy console (conhost.exe) font filtering via HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Console\TrueTypeFont.

5. WSL Interop Path Translation Warning (Y:\Program Files\Go\bin)

Diagnosis: The message wsl: Failed to translate 'Y:\Program Files\Go\bin' is emitted by WSL's microVM /init process when translating the Windows host PATH into Linux $PATH while drive Y: is offline or unmounted. Provided diagnostic commands and 1-line PowerShell surgical cleanup scripts to eliminate the stale path from Windows Machine/User environment variables.
