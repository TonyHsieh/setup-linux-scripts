1. Root Cause Resolution: Seamless, Zero-Flag home-manager switch

Incident: After upgrading to WSL 26.04 and running dry-run ./bootstrap.sh --build, running bare home-manager switch failed with No configuration file found. Please create one at ~/.config/home-manager/home.nix.
Root Cause: Home Manager defaults to looking for ~/.config/home-manager/flake.nix. When not found, it falls back to non-flake home.nix. Furthermore, when evaluating flakes without an explicit #target argument, Home Manager checks for homeConfigurations."$USER@$HOSTNAME" and homeConfigurations."$USER", which were not aliased in flake.nix.
Resolution: (1) Scaffolding automatic symlink ~/.config/home-manager -> $SCRIPT_DIR in bootstrap.sh.
