🐍 Incident 1: Nix hermes-agent-0.23.0 Kanban Workers Missing websockets & ruamel.yaml

Root Cause: numtide/llm-agents.nix injects ~120 Python 3.14 dependencies via site.addsitedir() inside .hermes-wrapped rather than exporting PYTHONPATH. When Hermes Kanban spawns workers via bare sys.executable -m hermes_cli.kanban_worker_client, the child Python interpreter loses all bundled site-packages.

Permanent Nix Fix: Added hermesAgentPatched in home/ai-agents.nix using pkgs.symlinkJoin + makeWrapper to automatically extract every /nix/store/.../site-packages path from .hermes-wrapped into PYTHONPATH. Preserves 100% of cache.numtide.com binary substitution (zero source rebuild) and auto-syncs on future jl update-agents runs. Tracked in AGENTS.md Temporary Patches Registry (target review: 2027-01-15).
