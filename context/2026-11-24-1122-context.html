🛠️ Solved Technical Incidents & Root Cause Analysis

🔍 Incident 1: Numtide Binary Cache Legitimacy & Public Key Verification

Question: During bootstrap.sh execution, Nix prompts to trust public key niks3.numtide.com-1:DTx8wZduET09hRmMtKdQDxNNthLQETkc/yaX7M4qK0g=. The end-user noted that *.com-1 resembled a suspicious or spoofed domain.

Root Cause & Verification: In the Nix ecosystem, cache public keys follow standard cryptographic format <cache-domain>-<key-id>:<base64-ed25519-public-key> (identical to official cache.nixos.org-1 and devenv.cachix.org-1). -1 denotes key revision 1 for Numtide, the core maintainer of llm-agents.nix. Accepting it enables cryptographically signed pre-compiled binaries, avoiding hours of local compilation for LLM agents.

Permanent Implementation: Added user-facing explanatory console banners in bootstrap.sh and documentation headers in flake.nix to reassure users during fresh bootstrap runs.

📱 Incident 2: KyBook 3 OPDS Missing Folders & Directory Truncation

Problem: When browsing large directory trees (such as RPG with 238 subfolders) via KyBook 3 on iOS/iPadOS, only 30 folders were visible.

Root Cause 1 (OPDS Navigation Bug): Ubooquity v3 folder navigation feeds (/opds/books/<id>) use opusPaginationNumber (default 30). Unlike book acquisition feeds, Ubooquity's navigation template (tpl-opds-navigation.xml) lacks rel="next" pagination links, causing all OPDS clients to truncate folder listings at 30 items.

Root Cause 2 (Java Heap OOM & Empty Folder Pruning): The container defaulted to 512 MB RAM (-Xmx512m). Scanning massive, multi-hundred-megabyte RPG PDFs caused java.lang.OutOfMemoryError: Java heap space. Files that failed insertion caused Ubooquity to treat parent folders as empty and automatically delete them from the database.

Permanent Fix & Verification:

  • Added MAXMEM=${UBOOQUITY_MAXMEM:-4096} to local-services/docker-compose.yml to provide 4 GB heap space.
  • Set opusPaginationNumber and booksPaginationNumber to 5000 in preferences-2.json and preferences.json.
  • Recreated container; live query of /opds/books/12748 confirmed entries jumped from 30 to 233 folders.
  • Documented complete architecture and tuning steps in docs/books-server.md.
