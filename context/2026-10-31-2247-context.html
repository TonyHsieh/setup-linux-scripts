🛠️ Incident Resolution: WSL2 GPU Driver & Nix Linker Failure

Symptom: Inside nn-zero-to-hero, nvidia-smi succeeded but PyTorch reported Found no NVIDIA driver on your system and fell back to CPU.

  • Root Cause Diagnosed: In WSL2, Windows paravirtualizes GPU access through /dev/dxg and mounts driver shims into /usr/lib/wsl/lib. While native Ubuntu binaries locate it via /etc/ld.so.conf.d/ld.wsl.conf, Nix-built binaries bypass /etc/ld.so.cache completely and only inspect RPATH and LD_LIBRARY_PATH.
  • Zero-Pollution Fix:
    1. In templates/python/devenv.nix: Added automatic [ -d "/usr/lib/wsl/lib" ] detection in enterShell. Direnv unloads the path cleanly upon folder exit.
    2. Self-Healing Hook: Automatically injects activation and deactivation restoration into .devenv/state/venv/bin/activate if devenv ever rebuilds the venv.
    3. Host Integration in home/wsl.nix: Guaranteed nvidia-smi in PATH and added wsl-cuda and patch-venv-cuda functions.
