> [!CAUTION]
> **DO NOT run `uninstall-dev-env.sh` directly!**  
> The legacy uninstall script was written for the old imperative setup. Running it blindly could remove active Home Manager symlinks (like `~/.bashrc`, `~/.config/nvim`, or `~/.nix-profile`).

### How Nix Isolates Your Environment
All your active v2.0 packages live safely in `/nix/store/` and are symlinked into `~/.nix-profile/bin`. System paths like `/usr/local/bin` and system package managers (`apt`) are no longer used by your developer environment.

### Safe Legacy Cleanup Checklist

1. **Remove Stale Manual Binaries in `/usr/local/bin`**:
   The old scripts downloaded binaries directly into `/usr/local/bin`. Since Nix now provides modern versions in `~/.nix-profile/bin`, you can safely prune the old duplicates:
   ```bash
   # Inspect what manual binaries exist:
   ls -la /usr/local/bin/

   # Safely remove old imperative downloads (Nix versions take precedence in PATH):
   sudo rm -f /usr/local/bin/k9s /usr/local/bin/sops /usr/local/bin/yq /usr/local/bin/age /usr/local/bin/age-keygen
   ```

2. **Clean Up Old LunarVim Artifacts (if any remain)**:
   ```bash
   rm -rf ~/.local/share/lunarvim ~/.cache/lvim ~/.config/lvim ~/.local/bin/lvim
   ```

3. **Prune Old Imperative Dotfile Backups**:
   List and remove stale `.bak` or timestamped backups created during testing:
   ```bash

   ls -la ~/.bashrc.backup-* ~/.bashrc.bak* 2>/dev/null || true

   # Clean up backups older than today once satisfied:
   # rm -f ~/.bashrc.backup-*
   ```
