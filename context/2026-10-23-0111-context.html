⚡ Session 2026-10-23: ble.sh Restoration, Tmux Multi-Pane Layouts & Session Pruning

✅ Milestone Complete: Shell Modernization & Multiplexer Resilience
Fully restored ble.sh terminal line editor across interactive sessions while maintaining safe devenv shell subshell suppression; configured Tmux detached canvas to 350x90 to ensure arbitrary multi-pane tiled layouts (3, 4, 6+ panes) restore without clipping; eliminated ghost session proliferation; hot-reloaded configuration with zero downtime to the user's active session.
Technical Deep-Dive: Shell & Tmux Resolutions
Component Trigger & Failure Mechanism Permanent Resolution
ble.sh Subshell Suppression In commit 3535c97, -z "${BLE_SESSION_ID:-}" was added as a subshell guard. However, ble.sh explicitly exports BLE_SESSION_ID on line 9703. Every child process, terminal window, and tmux pane inherited this exported environment variable, causing the guard to evaluate to false and completely disabling ble.sh across the entire machine. Removed -z "${BLE_SESSION_ID:-}" in home/shell.nix while retaining -z "${DEVENV_ROOT:-}" and -z "${IN_NIX_SHELL:-}". ble.sh attaches cleanly in interactive bash/tmux, and remains properly suppressed inside devenv shell subshells.
Tmux Tiled Window Restoration (N-Panes) Headless/detached sessions spawned by tmux-continuum default to default-size 80x24. Complex multi-pane tiled layouts (e.g. 346x79 with 3, 4, or 6 panes) were rejected by tmux because they exceeded the 80x24 canvas and minimum pane cell constraints. Layout errors were silenced (>/dev/null 2>&1), leaving panes vertically stacked. Added set -g default-size 350x90 in home/tmux.nix, providing 31,500 virtual character cells so multi-pane layouts restore cleanly. Preserved custom split ratios (e.g. 55-line top vs 23-line bottom) by avoiding aggressive equalize hooks. Enabled @resurrect-capture-pane-contents 'on'.
Tmux Ghost Sessions & Manual Session Selection Invoking tmux without arguments repeatedly created unattached single-pane numbered sessions (3, 4, 5, 6). Continuum saved state 6, so upon restore, the user landed in a blank single pane and had to press Ctrl-B s to find Session 0. Added a smart tmux() shell launcher and t alias in home/shell.nix that automatically connects to the primary Session 0 if available. Pruned ghost sessions from the live server and saved resurrect snapshot with state 0.
Tmux Config Reload Keybinding In home/tmux.nix, bind r pointed to ~/.tmux.conf, but Home Manager deploys config to ~/.config/tmux/tmux.conf. Updated keybinding to source ~/.config/tmux/tmux.conf with fallback to ~/.tmux.conf.
Package & Plugin Versions Audit The user observed 2022 in Nix store paths and questioned package currency. Verified tmux 3.7c from the Oct 10, 2026 Nixpkgs lock. Confirmed upstream GitHub repositories for tmux-sensible, tmux-resurrect, and tmux-continuum have had no new releases since 2022–2024; they are mature, stable POSIX bash scripts. Documented in README.md.

Technical Deep-Dive: Networking & Remote Mesh Resolutions
Component Trigger & Failure Mechanism Permanent Resolution
Tailscale Serve Hostnames Tailscale MagicDNS only issues Let's Encrypt certificates for direct node names (<node>.<tailnet>.ts.net), not two-level subdomains (*.<node>...). Single container routing forced users to type awkward port numbers. Implemented Option 2: Created dedicated, lightweight Tailscale ingress containers (tailscale-pdf, tailscale-chat, tailscale-traefik, tailscale-ollama, tailscale-books), each taking ~15MB RAM and serving standard HTTPS on Port 443.
Mobile Safari Port 80 Rejection When accessing pdf-asus.komodo-sole.ts.net on iOS Safari, iOS probes HTTP Port 80 before TLS negotiation. Tailscale Serve only listened on Port 443, returning dial tcp 127.0.0.1:80: connect: connection refused. Updated all serve-*.json configuration templates to bind both Port 80 and Port 443. Mobile browsers now cleanly negotiate TLS without connection drops.
Nix Store Symlink Mount Collision Home Manager deployed ~/.local/share/local-services/tailscale/serve.json as a symlink pointing to /nix/store/.... Mounting the parent directory caused the container to see a broken symlink because /nix/store did not exist inside the container. Directly bind-mounted the file target in docker-compose.yml (tailscale/serve-*.json:/config/serve.json:ro). Podman resolves the symlink on the host, passing real contents into the container.
Docker Desktop Windows Credential Conflict Docker Compose failed to pull images in WSL2 due to exec: "docker-credential-desktop.exe": executable file not found in $PATH inherited from Windows Docker Desktop. Cleaned ~/.docker/config.json to eliminate the broken Windows helper in WSL2.
Justfile Shell Variable PID Escaping Recipes like remote-info used Makefile-style $$VAR, which bash expanded to the shell PID (e.g. 94467SUFFIX). Corrected variables to standard bash $VAR format and added ${VAR%.} parameter expansion to strip trailing DNS dots cleanly.
Multi-Machine Hardcoding Tailscale hostnames initially had -asus hardcoded, which would collide when deployed on another laptop. Parameterized hostnames with TS_MACHINE_ID (e.g. pdf-${TS_MACHINE_ID:-asus}), added .env.example, auto-detection in bootstrap.sh, and added wsl-thsieh in flake.nix.
