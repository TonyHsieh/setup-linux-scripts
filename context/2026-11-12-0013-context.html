🔍 Incident Analysis & Architecture Resolutions

1. Herdr Download 404 & Silent Skip Resolution RESOLVED

Root Cause: Upstream GitHub releases (herdrdev/herdr) publish standalone uncompressed executables named herdr-linux-x86_64, herdr-linux-aarch64, herdr-macos-aarch64, and herdr-macos-x86_64. The initial script assumed an archive named herdr-x86_64-unknown-linux-gnu.tar.gz. When curl failed with 404, it fell back to Cargo which failed silently with 2>/dev/null, printing an informational notice without exiting non-zero.

Fix: Corrected download asset URL in bootstrap.sh to fetch raw binary directly, execute chmod +x, move to ~/.local/bin/herdr, and create symlink ~/.local/bin/hc. Verified binary runs cleanly: herdr 0.9.5.

2. Bootstrap Verification Sequencing & Idempotency Gap RESOLVED

Root Cause: In bootstrap.sh, verify_deployment() was executed at Step 8, while install_herdr was called at Step 9+ (after the self-test had already reported "Verification passed!"). Furthermore, verify_deployment() lacked an assertion for herdr, and install_herdr returned exit code 0 on failure.

Fix: Moved install_herdr before verify_deployment(). Added a strict verification test in verify_deployment() that asserts ~/.local/bin/herdr exists and prints version. Ensured install_herdr returns 1 on failure to halt execution. Verified live test passes with 0 warnings.

3. Cross-Platform & Multiplexer Coexistence DOCUMENTED

Architectural Blueprint: Formulated clear operational paradigms for using Herdr with tmux, WSL2, and macOS:

  • With tmux: Herdr acts as the Layer 2 agent supervisor with an attention queue; tmux acts as the developer workbench. They can run headless in the background (Pattern A), nested inside a tmux window without prefix conflict (Pattern B: tmux Ctrl-b vs Herdr Ctrl-a), or side-by-side (Pattern C).
  • On WSL2: Runs as native Linux binary using WSL2 Linux kernel PTYs and Unix sockets; integrates with Windows Terminal; background persistence via WSL2 systemd.
  • On macOS: Native Mach-O binary for Apple Silicon (herdr-macos-aarch64) and Intel (herdr-macos-x86_64); works out-of-the-box with Ghostty, iTerm2, and Kitty.
