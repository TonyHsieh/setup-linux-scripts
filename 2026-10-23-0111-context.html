Technical Deep-Dive: Root Cause Analysis & Resolutions
Component Trigger & Failure Mechanism Permanent Resolution
ble.sh Subshell Suppression In commit 3535c97, -z "${BLE_SESSION_ID:-}" was added as a subshell guard. However, ble.sh explicitly exports BLE_SESSION_ID on line 9703. Every child process, terminal window, and tmux pane inherited this exported environment variable, causing the guard to evaluate to false and completely disabling ble.sh across the entire machine. Removed -z "${BLE_SESSION_ID:-}" in home/shell.nix while retaining -z "${DEVENV_ROOT:-}" and -z "${IN_NIX_SHELL:-}". ble.sh attaches cleanly in interactive bash/tmux, and remains properly suppressed inside devenv shell subshells.
Tmux Tiled Window Restoration (N-Panes) Headless/detached sessions spawned by tmux-continuum default to default-size 80x24. Complex multi-pane tiled layouts (e.g. 346x79 with 3, 4, or 6 panes) were rejected by tmux because they exceeded the 80x24 canvas and minimum pane cell constraints. Layout errors were silenced (>/dev/null 2>&1), leaving panes vertically stacked. Added set -g default-size 350x90 in home/tmux.nix, providing 31,500 virtual character cells so multi-pane layouts restore cleanly. Preserved custom split ratios (e.g. 55-line top vs 23-line bottom) by avoiding aggressive equalize hooks. Enabled @resurrect-capture-pane-contents 'on'.
Tmux Ghost Sessions & Manual Session Selection Invoking tmux without arguments repeatedly created unattached single-pane numbered sessions (3, 4, 5, 6). Continuum saved state 6, so upon restore, the user landed in a blank single pane and had to press Ctrl-B s to find Session 0. Added a smart tmux() shell launcher and t alias in home/shell.nix that automatically connects to the primary Session 0 if available. Pruned ghost sessions from the live server and saved resurrect snapshot with state 0.
Tmux Config Reload Keybinding In home/tmux.nix, bind r pointed to ~/.tmux.conf, but Home Manager deploys config to ~/.config/tmux/tmux.conf. Updated keybinding to source ~/.config/tmux/tmux.conf with fallback to ~/.tmux.conf.
Package & Plugin Versions Audit The user observed 2022 in Nix store paths and questioned package currency. Verified tmux 3.7c from the Oct 10, 2026 Nixpkgs lock. Confirmed upstream GitHub repositories for tmux-sensible, tmux-resurrect, and tmux-continuum have had no new releases since 2022–2024; they are mature, stable POSIX bash scripts. Documented in README.md.
