🐛 3. Incident: Let's Encrypt TLS Handshake Timeout on systemd-resolved Hosts
Symptom: Connecting from a mobile phone to https://pdf-envy.komodo-sole.ts.net yielded "A TLS error caused the secure connection to fail".
Root Cause: CachyOS uses systemd-resolved on the host, setting /etc/resolv.conf to 127.0.0.53. Rootless Podman bridge DNS (10.89.0.1) timed out forwarding ACME DNS queries to 127.0.0.53 from inside the user network namespace.
Fix: Created ~/.config/containers/containers.conf declaring dns_servers = ["1.1.1.1", "8.8.8.8"] and tracked it declaratively in home/default.nix. Let's Encrypt ACME verification resolved instantly and generated valid TLS certs across all nodes.
🐛 4. Incident: Port 80 Schema Bug ("HTTPS": false vs "HTTP": true)
Symptom: Typing http://books-envy.komodo-sole.ts.net failed with connection refused rather than redirecting to HTTPS.
Root Cause: In Tailscale's ipn.ServeConfig JSON schema, the TCP block requires "HTTP": true to denote a plain unencrypted HTTP listener. The config previously had "HTTPS": false, which Tailscale ignored and defaulted to TLS on Port 80.
Fix: Updated all serve-*.json files to use "80": { "HTTP": true } and verified that tailscale serve status binds port 80 as plain HTTP with a 301 Moved Permanently redirect to https://${HOST}${REQUEST_URI}.
🎬 5. Dedicated Port 443 Sidecar Added for Plex Media Server
